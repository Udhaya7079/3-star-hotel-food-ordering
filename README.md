# 🍽️ 3 Star – Hotel Food Ordering Website

A simple, elegant static website for **3 Star Hotel** that showcases signature dishes and lets visitors get in touch through a contact form. Built using pure **HTML** and **CSS**.

---

## 📌 Features

- **Header Navigation** – Clean black navbar with hotel branding and quick links (Home | Receipe | Contact)
- **Food Menu Section** – Four featured dishes displayed in a card layout:
  - 🍕 Pizza – A wood-fired classic topped with fresh tomatoes, olives, and melted cheese.
  - 🍔 Burger – A juicy grilled patty layered with crisp lettuce, tomato, and melted cheese.
  - 🍗 Roasted Chicken – Herb-marinated chicken roasted to a crispy golden finish.
  - 🍜 Noodles – Stir-fried noodles tossed with fresh vegetables in a rich, savory sauce.
- **Order Now Buttons** – Interactive hover effects on each food card
- **Contact Us Form** – Collects Name, Age, Email, and a Rating (dropdown selector)
- **Responsive Card Hover Effects** – Cards highlight on hover for better interactivity

## 🚀 Getting Started

1. Clone this repository
   ```bash

   ```
2. Navigate into the project folder
   ```bash

   ```
